# Gym Management System 🏋️‍♂️

A desktop application built using Python and MySQL to efficiently manage gym members and their subscription packages.

## 🚀 Features
- **User-Friendly GUI:** Clean interface built with Python Tkinter.
- **Member Registration:** Easily add new members with Name, Phone Number, and Package details.
- **Database Integration:** Securely stores all records directly into a MySQL database.

## 🛠️ Tech Stack
- **Programming Language:** Python
- **GUI Library:** Tkinter
- **Database:** MySQL
- **Connector:** mysql-connector-python
