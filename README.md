# College Admission Analysis System

A Python-based data analysis and visualization tool built using **Pandas** and **Matplotlib** to analyze college admission trends, branch-wise applications, and category distributions.

## 🚀 Features
- **Data Preprocessing & Loading:** Reads structured CSV datasets using Pandas with built-in error handling.
- **Multi-Feature Analysis:** Aggregates and summarizes total applications and admissions by branch and category.
- **Data Visualization:** Generates professional multi-chart dashboards (Bar charts and Pie charts) using Matplotlib.

## 📊 Tech Stack
- **Python** (Programming Language)
- **Pandas** (Data Manipulation & Analysis)
- **Matplotlib** (Data Visualization)
